# AutoGui 使用说明（通用部分）

各脚本完整参数见 [KeyPress.md](KeyPress.md) / [MouseClick.md](MouseClick.md) / [Recorder.md](Recorder.md)，本文件只讲公共约定：Main.py 用法、三态热键、运行终止机制、统一参数、预设文件。

## Main.py 统一入口

### 交互菜单

```bash
python Main.py
```

列出功能（keypress / mouseclick / record / replay），输入序号后按提示逐个填写常用参数（回车使用默认值），确认后以子进程方式执行。任务结束（真正结束 / 自然结束 / 等待阶段放弃）后自动回到菜单，输入 `0` 或 `q` 退出。

### CLI 直传（供脚本 / 批处理调用）

```bash
python Main.py <功能> <该功能的参数...>
```

例如：

```bash
python Main.py keypress -l a,d -r 0 -k1 q -k2 p -k3 space
python Main.py replay demo.json -r 0 --speed 2
python Main.py record -o demo.json -k1 f2
```

参数原样透传给对应脚本（校验与帮助由脚本自己负责，可用 `python Main.py keypress -h` 查看）。`python Main.py -h` 查看功能列表。

## 三态热键（开始 / 暂停 / 结束）

无限循环（`-r 0`）时可用三个全局热键控制执行状态，全部走 pynput 全局监听，**终端失焦也能生效**：

| 参数 | 功能 | 默认 |
|------|------|------|
| `-k1` / `--start-key` | 开始循环（初始启动；`-a` 时跳过等待直接开始） | `enter` |
| `-k2` / `--stop-key` | **结束**循环并退出脚本（真结束） | `esc` |
| `-k3` / `--pause-key` | **暂停 / 继续**：按一次暂停，再按一次恢复 | 未设置 = 关闭 |

典型用法——开始循环，暂停后直接恢复，按 `p` 真正结束：

```bash
python Scripts/KeyPress.py -l a,d -r 0 -k1 q -k2 p -k3 space
```

按 `q` 开始循环 → 按 `space` 暂停（注入停止、进程存活、打印暂停提示）→ 再按 `space` 恢复 → 按 `p` 真正结束。

限制：

- `-k3`（暂停键）**不得与 `-k1`、`-k2` 相同**，否则启动时报错（防止按下暂停键既暂停又结束/开始的混乱行为）。
- `-k1` 与 `-k2` **不得相同**（归一比较，能识别 `esc`/`escape` 等别名），否则启动时报错 —— 同一键会同时触发开始与结束监听，等待开始阶段按下即"弃权"，行为混乱。
- 只给 `-r 0` 无限循环；`-r N` 有限循环同样支持暂停/结束。

## 运行终止机制

| 途径 | 说明 |
|------|------|
| `-k2` 结束热键（推荐） | pynput 全局监听，**终端失焦也能终止**；等待开始阶段按它 = 干净放弃本次执行（打印 `Aborted before start`）并退出 |
| `Ctrl+C` | 仅当**终端窗口有焦点**时有效（操作时焦点一般在目标窗口，故作为备用手段） |
| pyautogui 失效保险 | 鼠标移到屏幕角落会中断操作，属兜底 |

> 真实使用场景下，开始/暂停/结束都依靠上面三个全局热键；等待开始阶段 `-k2` 就已生效，不必依赖 Ctrl+C。

## 参数统一约定

| 参数 | 统一语义 |
|------|----------|
| `-r`, `--repeat` | 重复轮数，`0` 表示无限循环（三个脚本均必填） |
| `-s`, `--start-delay` | 开始后缓冲秒数，默认 0（`-a` 时即启动后缓冲） |
| `-w`, `--wait` | 每轮结束后的纯轮间间隔（秒），默认 0 |
| `-a`, `--auto` | 跳过开始热键等待，直接执行 |
| `-k1`, `--start-key` | 开始热键，按下后才开始执行，默认 `enter`（`-a` 时跳过） |
| `-k2`, `--stop-key` | 结束热键，默认 `esc` |
| `-k3`, `--pause-key` | 暂停/继续切换热键，默认关闭 |
| 命令输入 | `-l, --list` 直接用逗号分隔列表；或 `-n, --num` 逐个交互输入；或传预设文件 `file` 加载，三者互斥 |

> **窗口焦点：** 脚本不会自动激活目标窗口。`-k1` 开始键就是焦点闸门——先切换/点击进入目标窗口，再按开始键才开始执行。`-a` 跳过该等待时，须在启动前把目标窗口置于前台：鼠标点击按绝对坐标路由、不受焦点影响，但键盘按键与 Recorder 回放跟随焦点窗口。

## 参数预设文件（KeyPress / MouseClick 录制与回放）

用 `-o/--output` 把"用户输入的配置"存为 JSON 预设，下次直接加载复用；只存命令/坐标与节奏，无时间轴、不存重复次数：

```json
{
  "version": 1,
  "type": "keypress",   // keypress / mouseclick
  "keys": ["up", "down", "left"],
  "clicks": [1, 2, 3],
  "positions": [[100, 200]],
  "delay": 0.5,
  "wait": 1.0
}
```

- `-o` **显式指定才保存**；回放用位置参数 `file` 加载，`-r` 必须在命令行指定（预设不保存重复次数）。
- CLI 显式给出的 `-d/-w` 覆盖预设值；未给出时取预设值，无预设则 `-d` 为 0.1、`-w` 为 0。
- `-s / -k1 / -k2 / -k3 / -a` 属执行环境，不入预设，始终走命令行。

> 与 Recorder.py 的真实操作录制不同：预设存的是参数快照，Recorder 存的是带时间轴的完整事件流。
